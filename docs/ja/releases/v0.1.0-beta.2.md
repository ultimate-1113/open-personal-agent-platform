# v0.1.0-beta.2

[English](../../en/releases/v0.1.0-beta.2.md)

Node.js 26 LTSに対応した更新版です。

- 開発環境・CI・Installer内蔵Runtime・Gateway BridgeをNode.js 26.13.0へ更新しました。ソースからの実行には26.13.0以上、27未満が必要です。
- Corepackへの依存を除去し、pnpm 11.23.0の固定を維持しました。
- Node 26の型定義に合わせてSecret VaultのWeb Crypto入力を調整しました。暗号化ファイル形式は変更ありません。
- Windows・Linux Installerは未署名です。起動前にHashとArtifact Attestationを確認してください。ソース公開やAttestationはコード自体の安全性を保証しません。
- Dynamic PluginとDiscord Gateway Bridgeは引き続き実験機能です。macOSの未署名開発BuildはActions Artifactで提供し、一般向け資産には含めません。

配置先のデータを削除する必要はありません。更新前にバックアップを取得してください。
