# v0.1.0-alpha.2

[English](../../en/releases/v0.1.0-alpha.2.md)

このAlpha版では、Phase 4のKnowledge API、TypeScript SDK、MCPを実装しました。

主な内容は次のとおりです。

- PublicとDelegatedの`POST /v1/query`
- Fixture、Static Site、AI Search、Google Drive、GitHubのKnowledge Source
- Source ACLとGatekeeper Resource Allowlistによる二重のResource Scope検証
- 配置単位Quota、Delegated Principal単位Quota、短時間Cache
- Gemma 4 26Bによる引用付き回答とAI費用Reservation
- OpenAPI 3.1、`@opap/sdk`、Stateless Streamable HTTP MCP
- 日英対応のKnowledge Source管理画面と利用例

Stagingでは、AI SearchのPublic EndpointとWorkers Binding、Google Drive、GitHubを実資格情報で確認しました。
Google DriveとGitHubはREST、TypeScript SDK、MCPから検索し、許可外Sourceの拒否も確認しました。
Google Driveの結果はWorkers AIへ送信し、引用付き回答まで確認しました。

Dynamic Sandbox PluginとProduction配置ProfileはPhase 5で実装します。
Discord Gateway Bridgeは引き続き実験機能です。
この版は公開ベータではありません。
