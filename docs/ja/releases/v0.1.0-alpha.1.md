# v0.1.0-alpha.1

[English](../../en/releases/v0.1.0-alpha.1.md)

このAlpha版では、Phase 3のConnector実装境界を完成させました。

主な内容は次のとおりです。

- Google、GitHub、DiscordのOwner Connector
- 承認付き外部書込と`unknown`結果の照合
- Owner Time Zoneに従う一回限りTaskと繰り返しTask
- Owner UIとDiscord DMのChat同期
- 非公開かつResource Allowlist付きのDelegated Source Gatekeeper
- 187件の自動Testと全Workerのdry-run build成功

Delegated Knowledge APIへの接続はPhase 4で実装します。
Discord Gateway Bridgeは引き続き実験機能です。
