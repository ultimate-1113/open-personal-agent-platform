# v0.1.0-beta.1

[English](../../en/releases/v0.1.0-beta.1.md)

Open Personal Agent Platformの最初の公開ベータです。

## 主な内容

- Cloudflare Accessで保護されたOwner専用Web UI
- WebとDiscordで共有するチャット、タスク、承認、監査
- Gmail、Google Calendar、Google Drive、GitHub Connector
- PublicとDelegatedのKnowledge API、TypeScript SDK、Streamable HTTP MCP
- Gemma 4 26Bと配置単位のAI・非AI費用制御
- Conversation Export、削除、Audit Retention、Private R2 Checkpoint
- 日英表示とライト・ダークテーマ
- 監査可能なWindows・Linuxセットアップウィザード
- Static Pluginと実験的Dynamic Sandbox Plugin

## 安定性

`cloud-base`をベータ対象とします。

Dynamic Plugin、Cloudflare Sandbox 1.0 Preview、`cloud-base-dynamic`、Discord Gateway Bridge、macOS未署名Buildは実験機能です。
macOS BuildはDeveloper ID署名とNotarizationが完了するまでGitHub Releaseへ添付せず、一般利用向けには配布しません。

セットアップウィザードのBinaryは署名されていない場合があります。
起動前に`SHA256SUMS`、GitHub Artifact Attestation、SBOM、固定CommitのSourceを確認してください。
AttestationはBuild元を示しますが、Code自体の安全性を保証するものではありません。

## 既知の制限

- 一つの配置につきOwnerは一人です。招待と複数テナントには対応しません。
- Gmail送信、GitHub Issue作成・コメント、Calendar予定作成などの外部書込には承認が必要です。
- Gmail送信はConnectorとして実装されていますが、外部受信側の配信結果までは保証しません。
- Cloudflareアカウント全体の利用量や分散攻撃による請求を、アプリ内Hard Limitだけで完全には制御できません。
- Dynamic PluginとDiscord Gateway Bridgeを無効にしても、Web Chat、Connector、Knowledge API、SDK、MCPは利用できます。

導入前に[Installerの安全性と検証手順](../operations/installer-security.md)を確認してください。
