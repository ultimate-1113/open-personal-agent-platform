# v0.1.0-alpha.2

[日本語](../../ja/releases/v0.1.0-alpha.2.md)

This alpha completes the Phase 4 Knowledge API, TypeScript SDK, and MCP implementation.

Highlights:

- Public and Delegated `POST /v1/query`
- Fixture, Static Site, AI Search, Google Drive, and GitHub knowledge sources
- dual resource-scope enforcement through source ACLs and Gatekeeper resource allowlists
- deployment-level quota, delegated-principal quota, and short-lived cache isolation
- cited answers with Gemma 4 26B and AI cost reservations
- OpenAPI 3.1, `@opap/sdk`, and stateless Streamable HTTP MCP
- bilingual Knowledge Source administration and usage examples

Staging verification covered the AI Search public endpoint and Workers Binding, plus real Google Drive and GitHub credentials.
Google Drive and GitHub searches passed through REST, the TypeScript SDK, and MCP, including denial of unauthorized sources.
Google Drive results also produced a cited Workers AI answer.

Dynamic Sandbox plugins and production deployment profiles remain Phase 5 work.
The Discord Gateway Bridge remains experimental.
This release is not the public beta.
