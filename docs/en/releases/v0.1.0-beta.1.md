# v0.1.0-beta.1

[日本語](../../ja/releases/v0.1.0-beta.1.md)

This is the first public beta of Open Personal Agent Platform.

## Highlights

- an owner-only Web UI protected by Cloudflare Access
- shared chat, tasks, approvals, and audit state across Web and Discord
- Gmail, Google Calendar, Google Drive, and GitHub connectors
- public and delegated Knowledge APIs, a TypeScript SDK, and Streamable HTTP MCP
- Gemma 4 26B with deployment-level AI and non-AI cost controls
- conversation export and deletion, audit retention, and Private R2 checkpoints
- Japanese and English UI with light and dark themes
- auditable Windows and Linux setup wizards
- Static Plugins and experimental Dynamic Sandbox Plugins

## Stability

The `cloud-base` profile is the supported beta configuration.

Dynamic Plugins, Cloudflare Sandbox 1.0 Preview, `cloud-base-dynamic`, the Discord Gateway Bridge, and unsigned macOS builds are experimental.
The macOS build is not attached to the GitHub Release or distributed generally until Developer ID signing and notarization are available.

Installer binaries may be unsigned.
Before running one, verify `SHA256SUMS`, its GitHub Artifact Attestation, the SBOM, and the source at the fixed commit.
Attestation identifies the build source; it does not guarantee that the code itself is safe.

## Known limitations

- Each deployment has one owner. Invitations and multi-tenancy are not supported.
- External writes such as Gmail delivery, GitHub issue creation and comments, and Calendar event creation require approval.
- Gmail delivery is implemented as a connector, but OPAP cannot guarantee final delivery by the receiving service.
- Application hard limits cannot fully cap account-wide Cloudflare usage or charges caused by distributed attacks.
- Web Chat, connectors, the Knowledge API, SDK, and MCP continue to work when Dynamic Plugins and the Discord Gateway Bridge are disabled.

Review [Installer security and verification](../operations/installer-security.md) before installation.
