# v0.1.0-beta.2

[日本語](../../ja/releases/v0.1.0-beta.2.md)

This update adds Node.js 26 LTS support.

- Updated development, CI, the bundled Installer runtime, and Gateway Bridge to Node.js 26.13.0. Source installations require Node.js >=26.13.0 and <27.
- Removed the Corepack dependency while retaining pinned pnpm 11.23.0.
- Adapted Secret Vault Web Crypto inputs to Node 26 type declarations without changing the encrypted file format.
- Windows and Linux Installers remain unsigned. Verify hashes and Artifact Attestations before launch. Public source and attestations do not guarantee code safety.
- Dynamic Plugins and Discord Gateway Bridge remain experimental. Unsigned macOS development builds are available as Actions artifacts, not general-download release assets.

Existing deployment data does not need to be deleted. Back up before updating.
